
# Scripts estadísticos

Esta carpeta contiene los códigos utilizados para el procesamiento y análisis de datos.

## Procedimientos

- Importación de bases de datos.
- Limpieza y transformación de datos.
- Estadística descriptiva.
- Estadística inferencial.
- Generación de tablas y gráficos.

## Herramientas

- R
- Python
- SPSS

Los procedimientos deben estar documentados para garantizar la reproducibilidad del análisis.
